Caesar Cipher in Python

A simple implementation of the Caesar Cipher encryption algorithm written in Python.

Features

- Encrypt text using a Caesar Cipher
- Decrypt encrypted text
- Supports uppercase and lowercase letters
- Preserves spaces, punctuation, and numbers
- Validates shift values (1–25)

How It Works

Each letter in the plaintext is shifted by a specified number of positions in the alphabet.
Example with a shift of 3:

Plaintext
HELLO

Ciphertext
KHOOR
